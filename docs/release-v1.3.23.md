# 杂鱼Max v1.3.23

网盘支持从 10 家扩到 15 家，新增的 5 家全部走完整链路：分享解析 → 目录浏览 → 取直链 → 转存 → 临时清理。

---

## 新增：5 家网盘

| 平台 | 分享解析 | 游客可用 | 登录方式 |
| --- | :--: | :--: | --- |
| **小飞机网盘**（feijipan） | ✓ | ✓ 全流程免登录 | 不需要 |
| **城通网盘**（ctfile） | ✓ | ✓ 全流程免登录 | 不需要 |
| **PikPak** | ✓ | 可浏览列表 | access_token / refresh_token |
| **联通云盘**（wopan） | ✓ | 可浏览列表 | Cookie / token |
| **天翼云盘**（189） | ✓ | 可浏览列表 | Cookie |

几个具体点：

- **小飞机**：整套匿名链路，粘链接直接就能下，不弹登录。
- **城通**：两跳取链，服务端给的等待时间会真等满再取；带提取码的分享自动识别；目录翻页走分享信息里的签名地址，不受提取码影响。
- **PikPak**：access_token 和 refresh_token 都收，填 refresh_token 会自动换发。转存是三步式，任务建立后轮询进度；同名同大小的文件会被识别并跳过重复下载。下载时 UA 必须带客户端版本号，这个已经写进请求头分派里。
- **联通云盘**：请求体 AES/CBC 加密，header 带时间戳签名，三段状态码（HTTP / STATUS / RSP_CODE）全部校验通过才算成功。
- **天翼云盘**：所有接口恒带 noCache 与 Sign-Type；登录失效判定覆盖 401 和任意 3xx；直链里的 `&amp;` 会还原成 `&`，`http://` 会升级成 https，避免下载中途被重定向打断。转存后新文件 id 不保证一致，按「文件名 + 大小」轮询确认。

## 新增：三家 token 平台登录界面

PikPak / 联通 / 天翼 在网盘页各有一张卡片。未登录时点卡片进登录弹窗，已登录时点卡片直接切到解析页，更多菜单里可以清除凭证。

凭证全部经 Android Keystore 加密后落盘，不明文存储。PikPak 的 refresh_token 会先真发一次换发请求验证；天翼会真拉一次个人目录列表验证，不是塞进去就算数。

未登录也不影响浏览分享内容里的文件列表 —— 取直链时才会提示登录。

## 修正

- **城通取链失败**：参数解析改成显式循环，不再依赖 lambda 内的 continue（低语言版本下这条路径行为不一致）。
- **网盘页假登录态**：上一版为了不让新平台被「隐藏未登录」过滤掉，把登录态写死成已登录。现在改成由真实存储驱动。
- **天翼接口**：修了一处异常分支里错误读取属性导致的崩溃。

## 界面

- 五家新平台各配了官方图标。
- 液态玻璃组件的尺寸自适应与胶囊比例独立化，小屏下不再挤在一起。
