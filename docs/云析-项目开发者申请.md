## 三、能力自证（均为基于云析源码的已落地实践）

1. **多平台登录态保活**：实现了平台无关的会话回写层（OkHttp 拦截器 + host 后缀注册表 + 增量合并落库），修复"个别平台莫名掉线"的快照冻结问题；覆盖百度 / 139 / 115，且不与夸克 / UC 自有的 `__puus` 刷新链路冲突。理解全局 Cookie 罐清空的连带风险，登出路径按域清理。
2. **百度网盘风控对策**：落地设备指纹独立化、取链后延迟清理（替代秒删）、下载线程默认下调、按 errno 细分可读错误提示等一揽子措施，并实测验证。
3. **并发安全**：为 token 轮换制平台的 refresh 流程补充单飞（Mutex + 锁内双重检查），修复并发刷新导致的凭据互相覆盖。
4. **独立模块实践**：在本地工程基础上搭建独立 `:admin` 模块（Compose 玻璃拟态 UI），复用主签名体系，熟悉多模块协作与 R8 规则踩坑（如 proguard 只支持 `#` 注释等）。
